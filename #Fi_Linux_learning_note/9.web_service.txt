"python -m http.server [port]" will launch a local web server:
Serving HTTP on 0.0.0.0 port 8000 (http://0.0.0.0:8000/) ...
and typing localhost:8000, will open the web, and you can visit

if under the dir, you have a index.html file, the web server will automaticly use it

another web server, type: php -S 127.0.0.1:[port]
the 127.0.0.1 is a loopback address, another way of saying localhost, always loop back
to yourself, your home
if you have file: favicon.ico, will use by default

another web server:  npx http-server -p 8086
another web server:  sudo systemctl start apache2, and open localhost:80
or you should: sudo nano /etc/apache2/ports.conf --> change listen: 80 to something
